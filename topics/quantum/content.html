The machine can recognise the prize, but it doesn't know where it is. A real one hides these squares and gives you only the look.

Each qubit doubles the boxes. The squares are now called amplitudes, and the chance is the amplitude squared. A step is one flip and one mirror. Each run ends in a single look, so the machine has to repeat the whole run.

Plain checks means opening that many boxes, then guessing among the rest. The dashed line shows noise, modelled as a chance each step wipes the state back to guessing. With noise on, the squares show chance only.

This search is the clearest demonstration, not the likely first job. Its gain is a square root, and error-corrected steps are slow: Babbush and colleagues judged such gains unlikely to pay off on early machines.

A qubit can be in a blend of 0 and 1, described by two amplitudes. Gates rotate those amplitudes; amplitudes can cancel or reinforce like waves (interference); and two qubits can be entangled, so measuring one tells you about the other. A quantum algorithm arranges interference so wrong answers cancel out. That helps for a few kinds of problems, such as simulating molecules and breaking some codes, not for everyday computing. The hard part is keeping qubits undisturbed: today's machines need error correction, which spends many physical qubits on each reliable logical one.
