Memory

Why do chips spend so much time waiting for memory?

A processor can do math far faster than memory can deliver the numbers. Chips hide that gap behind layers of memory: small and fast close by, big and slow further away. Follow a number from a cache, down to a single memory cell, and up to the stacks that feed an AI chip.

The memory hierarchyTypical access times

Processors hide slow memory behind layers of small, fast caches. A trip all the way to main memory costs hundreds of instructions' worth of time. HBM has roughly the same delay as ordinary DRAM but far more bandwidth, which is what AI chips need: they stream enormous amounts of data instead of fetching single values. Stacking memory: the HBM builder

HBM stacks DRAM dies on top of a logic base die, joined by thousands of vertical copper wires called through-silicon vias. The stack must still fit a fixed package height, so every extra layer means grinding each die thinner. Build a stack and see where it breaks.
