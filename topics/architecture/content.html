Architecture

Deciding what kind of machine to build

Before anyone draws a circuit, architects decide how the chip will think. Two layers matter. The instruction set architecture (ISA) is the vocabulary software uses to talk to hardware: instructions such as add, load and branch, and the exact bit pattern of each one. The microarchitecture is how one particular chip carries those instructions out: how many pipelines, how big the caches, how it predicts branches.

Many different chips speak the same ISA. AMD and Intel processors both run x86 programs. Apple, Qualcomm, AWS and NVIDIA each design different Arm chips. A program compiled for an ISA runs on every chip that implements it, so ISAs last for decades while microarchitectures change every year or two. Today three ISAs matter most.

x86-64 since 1978

Style
CISC (complex instruction set). Instructions are 1 to 15 bytes long and can work on memory directly. Modern x86 chips translate them internally into simpler, RISC-like micro-operations.
Who can build it
In practice only Intel and AMD, through a long-standing cross-license.
Where it wins
PCs and most servers by unit count. AMD and Intel shipped nearly 20 million EPYC and Xeon server processors in 2025. Its biggest asset is decades of software compatibility.
2026
Intel and AMD coordinate through the x86 Ecosystem Advisory Group (formed 2024). NVIDIA invested $5 billion in Intel, and the two are building custom x86 CPUs with NVLink and PC chips with RTX graphics chiplets.

Arm since 1985

Style
RISC (reduced instruction set). Every instruction is 4 bytes and only loads and stores touch memory. It was designed for low power from the start.
Who can build it
Anyone who pays Arm. Companies license ready-made cores (Cortex, Neoverse) or buy an architecture license to design their own cores, as Apple and Qualcomm do. Arm earns a royalty on every chip.
Where it wins
Nearly every smartphone, Apple Macs, Snapdragon Windows laptops, and cloud CPUs such as AWS Graviton, Google Axion, Microsoft Cobalt and NVIDIA Grace and Vera.
2026
Arm-based servers passed 45% of server revenue in Q1 2026 (IDC), carried by AI racks. In March 2026 Arm unveiled its first chip of its own, the AGI CPU: 136 Neoverse V3 cores on TSMC N3P, co-designed with Meta.

RISC-V since 2010

Style
RISC with a tiny base of about 40 integer instructions, plus optional extensions: multiply (M), atomics (A), floating point (F, D), compressed 2-byte instructions (C) and vectors (V).
Who can build it
Anyone, royalty-free. The standard is run by RISC-V International. Companies sell cores (SiFive, Andes, Alibaba's XuanTie, Tenstorrent) or design their own.
Where it wins
Billions of microcontrollers and the small control processors hidden inside other chips, including GPUs and SSDs. It is also growing in AI accelerators and in China.
2026
The RVA23 profile (ratified 2024) fixes one feature set for full computers. Ubuntu 26.04 LTS uses RVA23 as its baseline, and RVA23 boards are moving from labs into products.

An instruction is just 32 bits

Software is stored as numbers. The processor's decoder reads the lowest 7 bits (the opcode) to learn the instruction's format, sends the register numbers to the register file, and sends the function bits to the arithmetic unit. Build a RISC-V instruction and watch its bits change.

Pipelining: an assembly line for instructions

Each instruction passes through five steps: fetch it (IF), decode it and read registers (ID), execute (EX), access memory (MEM) and write the result back (WB). A pipelined processor overlaps them, so five instructions are in flight at once and ideally one finishes every clock cycle. Trouble starts when an instruction needs a result that isn't ready yet, and the pipeline must stall. Turn on forwarding (extra wires that pass a result straight to the next instruction) or let the compiler reorder the code, and watch the stalls disappear.

    A few fast cores, or thousands of simple ones?

    A CPU has a handful of large, fast cores built to finish one task quickly. A GPU has thousands of small lanes that are slow alone but powerful together. Which wins depends on how much of the work can run in parallel. Amdahl's law gives the answer: speedup = 1 ÷ ((1 − p) + p ÷ N), where p is the parallel share and N the number of cores. The serial part never gets faster, so it eventually dominates.

    Speedup is relative to one core. Each GPU lane is individually slower than a CPU core, so in practice the parallel share must be even higher for a GPU to win. That is why systems pair both: CPUs for control and serial code, accelerators for the math.

    The memory hierarchyTypical access times

    Processors hide slow memory behind layers of small, fast caches. A trip all the way to main memory costs hundreds of instructions' worth of time. HBM has roughly the same delay as ordinary DRAM but far more bandwidth, which is what AI chips need: they stream enormous amounts of data instead of fetching single values.
