Tiny chip studio

Design a tiny chip

Take one small circuit through the same eight steps as a billion-transistor GPU: write the logic, prove it works, turn it into gates, lay it out on silicon, make masks, fabricate, test and ship. Every step uses the real method in miniature, and every step feeds the next, so a bug you miss early shows up later. A ninth step, Make it real, exports your design as Verilog for real open-source chip tools and a community shuttle that makes actual chips.

Build the CPU from your own gates. The project ALU slice for the CPU is one bit of a processor's arithmetic-logic unit. The RISC-V lab copies your slice 32 times and runs its programs on it, so if your gates have a bug, the processor gets sums, comparisons and loops wrong.

The tiny hardware language

              
a & bAND: 1 only if both are 1
a | bOR: 1 if either is 1
a ^ bXOR: 1 if they differ
~aNOT: flips 0 and 1
( )Group, as in algebra
w = …;Any new name is an internal wire
// noteA comment

              
Real chips are written in SystemVerilog or VHDL. This language keeps only the part that describes logic, so every line becomes real gates. Each line describes hardware that always exists, not steps that run one after another.

From simulation to real silicon

            
Everything so far ran on simplified tools in your browser. Real chips go through the same steps with real tools, and many of the best ones are open source. Your design exports below as a ready Tiny Tapeout project. Tiny Tapeout is a community shuttle: hundreds of small designs share one real chip, so each designer pays for a small tile instead of a whole mask set.

How to tape it out

              
    
                
  1. Download the project above.
    2. 
                
  2. On GitHub, open the Tiny Tapeout GF180 template and choose Use this template to make your own repository.
    3. 
                
  3. Copy in the files from the zip, replacing the template's versions, and push.
    4. 
                
  4. GitHub Actions runs the real flow: Yosys synthesis, LibreLane with OpenROAD for place and route, design-rule checks, a gate-level test, and a 3D view of your layout. If a step fails, its log says why.
    5. 
                
  5. Submit the repository to a shuttle at app.tinytapeout.com and pay for a tile.
    6. 
                
  6. Months later, your chip arrives on a board with switches and LEDs. Set ui_in, read uo_out.
    7. 
              

              

            

          

          
The exported Verilog is generated from your design and checked against it. Open Silicon Lab's own tests run every built-in project's export through Icarus Verilog and Yosys, but your edits are not run through the full flow here: the GitHub Actions in your repository do that. Shuttle dates and prices change, so check tinytapeout.com before you pay.
