Placing a billion cells so the wires stay short

After synthesis the design is a netlist: a list of cells and the nets (wires) connecting them. Placement decides where each cell sits. Long wires are slow and burn power, so tools minimize total wirelength while avoiding congestion.

The simulation runs simulated annealing, a classic placement algorithm. It swaps cells at random, always keeps swaps that shorten wires, and sometimes keeps bad swaps while the "temperature" is high so it can escape local traps.
